# 🎯 ПРОЕКТ: StudCareer

## 1. ОПИСАНИЕ ПРОЕКТА

**StudCareer** — платформа стажировок для студентов и людей без опыта работы
в Узбекистане. Это НЕ классический джоб-борд (не HH.ru), а "трекер стажировок".

### Ключевая идея:
У студента нет опыта, и ему нечего писать в резюме. Платформа позволяет
набирать опыт через стажировки, и он АВТОМАТИЧЕСКИ фиксируется в профиле.

### Жизненный цикл:
Студент находит стажировку → Откликается → Проходит отбор →
Стажзируется (1-6 месяцев) → Стажировка завершается →
В профиле автоматически появляется запись об опыте →
Резюме "растёт" с каждой стажировкой.

### Название: StudCareer (временное, может измениться)

---

## 2. РОЛИ И ПРАВА

### 2.1 Студент
- Регистрация и заполнение анкеты
- Поиск стажировок (доступно без регистрации)
- Отклик на стажировку (только после регистрации)
- Чат с работодателем
- Просмотр таймера своей стажировки
- Экспорт резюме (PDF/DOCX)
- Получение уведомлений
- Избранные стажировки
- Подача жалоб

### 2.2 Работодатель
- Регистрация и создание профиля компании
- Прохождение верификации админом
- Публикация стажировок
- Получение и рассмотрение откликов
- Принятие/отклонение студентов (с автописьмом)
- Управление стажёрами (таймеры)
- Завершение стажировок
- Просмотр архива "Законченные стажёры"
- Статистика + экспорт PDF/Excel
- Чат со студентами
- Получение уведомлений
- Подача жалоб

### 2.3 Админ
- Модерация стажировок
- Верификация компаний
- Бан пользователей
- Обработка жалоб
- Статистика платформы

---

## 3. ПОЛЬЗОВАТЕЛЬСКИЕ СЦЕНАРИИ

### 3.1 Путь студента:
1. Заходит на сайт БЕЗ регистрации
   → Видит главную: поиск, популярные стажировки, как работает
   → Просматривает каталог, фильтрует, читает описания
2. Хочет откликнуться
   → Кнопка "Откликнуться" → "Войдите или зарегистрируйтесь"
   → Регистрация (email + пароль)
3. Заполняет анкету
   → Фото, вуз, курс, навыки, языки, о себе, портфолио
   → Анкета = его резюме
4. Откликается на стажировку
   → Автописьмо генерируется (шаблон + стиль + язык)
   → Студент может редактировать или отправить как есть
   → Отправляется в чат на сайте
5. Работодатель принимает
   → Уведомление студенту
   → Таймер стажировки начинается
6. Стажировка завершена
   → Работодатель нажимает "Завершить"
   → Опыт автоматически добавляется в профиль
   → Резюме студента растёт
7. Студент может экспортировать резюме в PDF/DOCX

### 3.2 Путь работодателя:
1. Регистрация → создание профиля компании
2. Верификация админом (статус "На проверке" → "Верифицирована")
3. Публикация стажировки
4. Получение откликов → уведомления
5. Просмотр профилей студентов (их резюме)
6. Принятие/отклонение (автописьмо, можно редактировать)
7. Управление стажёрами (таймеры)
8. Завершение стажировки → опыт студенту
9. Архив "Законченные стажёры" + статистика + экспорт

### 3.3 Путь админа:
1. Вход в админ-панель
2. Верификация компаний
3. Модерация стажировок
4. Обработка жалоб
5. Бан пользователей
6. Статистика платформы

```python
class User(AbstractUser):
    """Кастомный пользователь с ролями"""

    class Role(models.TextChoices):
        STUDENT = 'student', 'Студент'
        EMPLOYER = 'employer', 'Работодатель'
        ADMIN = 'admin', 'Администратор'

    role = models.CharField(max_length=20, choices=Role.choices)
    email = models.EmailField(unique=True)
    phone = models.CharField(max_length=20, blank=True)
    avatar = models.ImageField(upload_to='avatars/', blank=True)
    preferred_language = models.CharField(
        max_length=5,
        choices=[('ru','Русский'),('uz','Узбекский'),('en','Английский')],
        default='ru'
    )
    is_verified = models.BooleanField(default=False)
    is_banned = models.BooleanField(default=False)
    accepted_terms = models.BooleanField(default=False)  # ToS
    created_at = models.DateTimeField(auto_now_add=True)

    USERNAME_FIELD = 'email'
    REQUIRED_FIELDS = ['username', 'role']
```

```python
class Skill(models.Model):
```

```python
    slug = models.SlugField(unique=True)
    description = models.TextField()
    requirements = models.TextField(blank=True)

    # Оплата

    salary_amount = models.PositiveIntegerField(null=True, blank=True)
    currency = models.CharField(max_length=3, default='UZS')

    # Длительность
    duration_months = models.PositiveSmallIntegerField(default=1)

    location = models.CharField(max_length=255, blank=True)
    deadline = models.DateField(null=True, blank=True)

    is_active = models.BooleanField(default=True)
    is_featured = models.BooleanField(default=False)
    views_count = models.PositiveIntegerField(default=0)

    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)


class InternshipSkill(models.Model):
    """Требуемые навыки для стажировки"""

    start_date = models.DateField(null=True, blank=True)
    end_date = models.DateField(null=True, blank=True)
    position = models.CharField(max_length=255, blank=True)  # Роль стажёра
    completed_at = models.DateTimeField(null=True, blank=True)
```

## 9. ТЕСТИРОВАНИЕ

### Правила:
- Каждая модель должна иметь тесты на валидацию
- Каждый view должен иметь тесты на доступ (роли)
- Каждый API endpoint должен иметь тесты
- pytest + pytest-django + factory_boy
- Coverage минимум 80%

### Примеры тестов:

```python
# tests/test_profiles/test_resume.py
import pytest
from django.urls import reverse

@pytest.mark.django_db
class TestResumeBuilder:
    def test_student_can_access_builder(self, student_client):
        url = reverse('profiles:builder')
        response = student_client.get(url)
        assert response.status_code == 200

    def test_employer_cannot_access_builder(self, employer_client):
        url = reverse('profiles:builder')
        response = employer_client.get(url)
        assert response.status_code == 403

    def test_export_pdf(self, student_client, student_profile):
        url = reverse('profiles:export_pdf')
        response = student_client.get(url)
        assert response.status_code == 200
        assert response['Content-Type'] == 'application/pdf'


# tests/test_internships/test_application.py
@pytest.mark.django_db
class TestApplication:
    def test_student_can_apply(self, student_client, internship):
        url = reverse('applications:apply', args=[internship.id])
        data = {
            'cover_letter': 'Хочу стажироваться',
            'letter_language': 'ru',
            'letter_style': 'formal',
        }
        response = student_client.post(url, data, HTTP_HX_REQUEST='true')
        assert response.status_code == 200

    def test_cannot_apply_twice(self, student_client, internship, existing_application):
        url = reverse('applications:apply', args=[internship.id])
        response = student_client.post(url, {}, HTTP_HX_REQUEST='true')
        assert response.status_code == 400

    def test_employer_can_accept(self, employer_client, application):
        url = reverse('applications:accept', args=[application.id])
        response = employer_client.post(url, HTTP_HX_REQUEST='true')
        assert response.status_code == 200
        application.refresh_from_db()
        assert application.status == 'accepted'


# tests/test_internships/test_completion.py
@pytest.mark.django_db
class TestInternshipCompletion:
    def test_employer_can_complete(self, employer_client, participant):
        url = reverse('internships:complete', args=[participant.id])
        response = employer_client.post(url, HTTP_HX_REQUEST='true')
        assert response.status_code == 200
        participant.refresh_from_db()
        assert participant.status == 'completed'

    def test_experience_created_after_completion(self, employer_client, participant):
        url = reverse('internships:complete', args=[participant.id])
        employer_client.post(url, HTTP_HX_REQUEST='true')
        student_profile = participant.student.student_profile
        assert student_profile.internship_experiences.count() == 1
```

## 11. КОНВЕНЦИИ КОДА

### Python / Django:
- Type Hints для всех функций
- Docstrings для классов и публичных методов
- Ruff форматирование (line-length=100)
- snake_case для функций/переменных, PascalCase для классов
- URL patterns: path() с именами (namespace:app_name)
- Views: CBV (CreateView, UpdateView, ListView) где возможно
- Формы: Django Forms с кастомными виджетами Tailwind

### Templates:
- Наследование от base.html
- Компоненты в templates/components/
- Partials для HTMX-ответов
- {% include %} для переиспользования
- i18n: все строки через {% trans %}

### HTMX:
- Ответы сервера возвращают partial templates
- hx-indicator для skeleton loaders
- hx-target указывает конкретный элемент
- hx-swap="outerHTML" для замены, "beforeend" для добавления
- hx-confirm для деструктивных действий

### Alpine.js:
- x-data для локального состояния
- x-show + x-transition для модалок, дропдаунов
- x-model для two-way binding
- @click.away для закрытия дропдаунов
- x-cloak для предотвращения мигания

### Git:
- Conventional Commits: feat:, fix:, docs:, refactor:, test:, chore:
- Ветки: feature/xxx, fix/xxx, refactor/xxx
- PR с описанием изменений
